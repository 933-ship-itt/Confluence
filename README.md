# Confluence

Confluence was an early-stage interface prototype exploring a dashboard for browsing token-style project listings. The work focused on the visual direction and interaction concepts for an intro screen, expandable sidebar, dashboard tabs, listing cards, and a wallet connection flow.

This repository contains a single-file HTML draft. It was an initial prototype, not a production application. The original plan was to move the work into a Next.js project, but that transition did not happen.

## Project status

This project is discontinued and is not being developed further. It reached a dead end because of regulatory issues, deficiencies in the prototype code, and a lack of funding. It should not be treated as a live service or used to make financial decisions.

## Running the prototype

Open `index.html` in a browser to view the draft interface. Some screens and interactions are placeholders; the repository does not include a production backend or deployment setup.

## Notes

The project is preserved as a record of the design and implementation work completed before development stopped. It is not production-ready, and no support or continued maintenance is planned.
